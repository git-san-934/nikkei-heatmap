# requirements.md — 更新ボタンの追加

## この作業でやること
画面に「更新」ボタンを追加する。ボタンを押すと、ページを再読み込みせずに
`data/constituents.json` / `data/heatmap.json` を再取得し、ヒートマップと
日経平均株価の表示を最新の内容に描画し直す。

## 背景・前提
- 本サイトはサーバーを持たない静的サイト。株価データは GitHub Actions が
  平日・場中に1時間おきに取得し、`data/heatmap.json` を更新している。
- そのため「更新」ボタンを押しても、Yahoo Financeへその場で株価を取りに行く
  ことはできない。取得できるのは「直近のActions実行で公開済みの最新データ」まで。
- ユーザーはこの前提（A案）に合意済み。

## ユーザーストーリー
- 個人投資家として、ページを開いたまま数十分経ったとき、ページ全体を
  リロードしなくても最新の状況に更新したい。

## 受け入れ条件
1. ヘッダーの操作エリアに「更新」ボタンが表示される。
2. ボタンを押すと `data/constituents.json` と `data/heatmap.json` を再取得する。
3. 取得した最新データでヒートマップ（タイルの色・サイズ・ツールチップ内容）を再描画する。
4. 取得した最新データで、タイトル横の日経平均株価（前日比 円・％）の表示も更新する。
5. 更新時刻表示（`#updated`）も新しい `updated_at` に更新する。
6. 更新中はボタンを操作不能にする、または連打で二重実行が起きないようにする。
7. 通信に失敗した場合、既存の表示は維持したまま、エラーが分かるようにする
   （ページ全体を壊さない）。
8. 選択中の期間（1日／1週間／1ヶ月）は更新後も維持される。

## 制約事項
- サーバーやAPIは新設しない。既存の静的JSON（GitHub Pages配信）を再取得するのみ。
- 「更新」を押した瞬間の実際の最新株価を保証するものではない
  （既存の「株価は約15〜20分遅れ」＋Actionsの実行間隔に依存する）。
- 既存の自動更新（GitHub Actions）やデータフォーマットは変更しない。
