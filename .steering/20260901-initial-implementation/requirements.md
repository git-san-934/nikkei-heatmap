# requirements.md — 初回実装（日経平均ヒートマップ）

## この作業でやること
日経平均株価の採用225銘柄の値動きを、色分けした四角形のタイル（ヒートマップ／ツリーマップ）で
一覧できるWebページを作る。誰でもブラウザで開けるよう GitHub Pages に公開する。

## ユーザーストーリー
- 個人投資家として、今日の相場全体が「上げ」か「下げ」か、どの業種が強い／弱いかを一目で把握したい。
- スマホでも見やすく開きたい。
- 値動きの期間（1日・1週間・1ヶ月）を切り替えて眺めたい。

## 受け入れ条件
1. 225銘柄すべてが業種ごとにまとまって表示される。
2. 各タイルの**大きさ**＝会社の規模（時価総額 ≒ 発行株数 × 株価）。
3. 各タイルの**色**＝選んだ期間の騰落率。値上がり=赤、値下がり=緑、変わらず=グレーのグラデーション（日本式）。
4. 「1日 / 1週間 / 1ヶ月」の切り替えボタンがある。初期表示は「1日」。
5. タイルをタップ／マウスを乗せると、銘柄名・証券コード・株価・騰落率が出る。
6. 画面上部にデータの更新時刻と「株価は約15〜20分遅れ・投資判断は自己責任」の注意書きを表示。
7. 平日の東京市場が開いている時間帯、1時間おきにデータが自動更新される。
8. スマホ幅でも横スクロールなしで見られる。ダークモード対応。
9. ポータル（https://git-san-934.github.io/portal/）からリンクで開ける。

## 制約事項
- サーバーは持たない。GitHub Pages（静的ホスティング）のみ。無料の範囲で完結させる。
- 株価取得は無料データソース（Yahoo Finance / yfinance）。取得できない銘柄が一時的に出ても
  ページ全体は壊れない（その銘柄はグレー表示）。
- 個人情報・ログインは扱わない。ページに保存されるデータもなし。
