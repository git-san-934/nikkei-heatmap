# プロダクト要求定義書 — 日経平均225 ヒートマップ

## ビジョン・目的
日経平均株価の採用225銘柄の値動きを、1画面で直感的に把握できるようにする。
個人が「今日の相場の雰囲気」「強い業種・弱い業種」を数秒で読み取れることを目指す。

## ターゲットユーザーと課題
- 日本株を見ている個人投資家。
- 課題: 個別銘柄の株価表を1つずつ見ても、相場全体の傾向がつかみにくい。
  ニュースの「日経平均○円高」だけでは中身（どこが牽引したか）が分からない。

## 主要な機能
1. 225銘柄を業種ごとにまとめたツリーマップ表示。
2. タイルの大きさ＝時価総額の概算、色＝騰落率。
3. 期間切り替え（1日 / 1週間 / 1ヶ月）。
4. タイルの詳細表示（銘柄名・コード・株価・騰落率）。
5. データの自動更新（平日・場中は毎時）。

## 成功の定義
- スマホ／PCのブラウザで開いて、相場全体の色味が一目で分かる。
- 平日にアクセスすれば、当日の値動きが（最大1時間＋15〜20分遅れで）反映されている。
- ポータルページから遷移して使える。

## ビジネス要件
- 運用コストゼロ（GitHub の無料枠のみ）。
- 個人情報・アカウントを扱わない。

## 受け入れ条件（初版）
`.steering/20260901-initial-implementation/requirements.md` を参照。

## 非機能要件
- 静的ホスティング（GitHub Pages）で動作すること。
- 主要ブラウザの最新版で表示崩れがないこと。ダークモード対応。
- スマホ幅で横スクロールが発生しないこと。
- 外部データ取得に失敗しても画面全体は壊れないこと。
